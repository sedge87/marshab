# Mission Operations — Acceptance checklist

- [ ] Console, map board and rack look visually consistent alongside the latest white/aluminium Hydroponics and Life Support GLBs.
- [ ] No floating parts, disconnected cable ends, backwards letters or static fake numerical displays.
- [ ] Survey board screen shows its map **facing the player correctly**, never mirrored.
- [ ] Mars overview comes from scientifically grounded source before classroom use.
- [ ] Local terrain and mission pins match the actual game world before classroom use.
- [ ] 2.44 m board fits its placement area without altering structural walls.
- [ ] Props face the right direction, have sensible simple collision and do not block navigation.
- [ ] Console can select a mission and show short requirements from live data.
- [ ] Rover missions, samples and science-lab state are connected when the actual game is integrated.
- [ ] Mission progress and discovered sites survive save/reload.
- [ ] No unnecessary additional real-time light sources or repeated active map viewports.
