# What this ZIP contains and what it does not

This is a **real, ready-to-use Codex work package** tailored to the uploaded October 2026 project, including a 46-item live catalogue snapshot, instructions, a grounded art direction, references and safety scripts.

It is **not** a completed set of 46 polished Blender models. Codex is being tasked to create, export, visually inspect and integrate those in stages. It contains links to view original NASA photographs and other reference imagery, rather than copying third-party photographs into the ZIP without confirming usage rights.

No original project files are changed by this ZIP. The backup helper must run inside the live repo before Codex modifies it. Existing projects may have newer changes than the ZIP: always use live repo as source of truth.
