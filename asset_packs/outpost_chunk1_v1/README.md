# Outpost One · Chunk 1 Models

Each asset folder contains its Godot GLB in `original/`, an editable Blender file in `source/`, and previews. The individual notes cover the named parts and the supplied visual controllers.

| Folder | Models |
| --- | --- |
| Power_Module | Towable power module |
| GAR_Y_Field_Upgrade | Weathered GAR-Y with the rear, front and mast mounts |
| GAR_Y_Tow_Hitch | Detachable hitch with separate reel and clip |
| Walker_1_Remake | Six-wheel Walker with the deployable habitat, dock, wheel seal and deck screen |
| Site_Plan_Terminal | Pedestal console with a live-screen mesh |
| Fitout_Crates | Small work light case, medium furniture case, and large terminal case |
| Landing_Pad_And_Beacon | Updated pad and beacon with the round centre dot inside the segmented ring |

The Walker renders show the separately supplied Power Module docked to the chassis. GAR-Y's rebuild reference is under its `source/reference/` folder.
