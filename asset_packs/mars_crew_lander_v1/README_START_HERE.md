# Crew Lander (MARS: HABITAT)

Where every game begins: a low-slung crew lander with a walkable cabin. Built in
Blender 5.2 from `source/build_lander.py` (`blender --background --python
build_lander.py -- <out_dir>`). About 7.6 x 4.7 x 6.8 m; cabin floor 1.1 m up;
the hatch door hinges at its bottom edge and lowers to the ground as the ramp.
Meshes ending `-col` get collision in Godot (hull, floor, sill, ramp, seats,
console, lockers, suit frame).
