# Review checklist — Indoor Heaters

- [ ] Wall unit mounts flush with the interior wall; no visual clipping and no changes to wall mesh.
- [ ] Portable unit rests on floor and rotates freely without clipping the player or room machinery.
- [ ] Geometry and materials render well in the game's real habitat lighting.
- [ ] Physical controls, mounting brackets, handle, feet, grille and filter align; no floating pieces.
- [ ] Status indicators only show when corresponding heater is powered and heating.
- [ ] OFF → LOW → HIGH → OFF works with existing interaction system.
- [ ] Low/high values request appropriate power from existing resource manager.
- [ ] Power outage stops effective heating (but preserves selected setting).
- [ ] Heating is applied to existing thermal system, not a separate or duplicate system.
- [ ] Placement and current setting survive save/load.
- [ ] Multiple heaters do not cause noticeable frame drops on target school laptops.
- [ ] No exterior placement; no corridor-only category restriction.
