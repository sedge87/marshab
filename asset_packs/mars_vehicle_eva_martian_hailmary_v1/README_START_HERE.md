# Vehicle Bay / EVA — The Martian + Project Hail Mary

Three separate GLBs for a Year 9 Mars Habitat game. White/light-grey composite skins, brushed aluminium, practical accents. Godot +Y up / -Z front.

## Models
- `suit_rack.glb` — two secured EVA suit docks. Inspect, prepare, service suit.
- `rover_charger.glb` — charging cabinet with reel and plug. Connect rover to charge.
- `eva_tool_station.glb` — tool and dust service workbench. Equip tools, prepare samples.

Mesh components have descriptive names for future interaction. **These interactions are not implemented**. The simple Godot review project provides an assembled visual scene only. Actual terrain, lighting, collision, and footprint must be checked in the real habitat.

Previous versions are not overwritten. Do not place this equipment in the structural kit. No baked text or mock dashboards.
