# Landmarks of the region (15 Nov 2026)

*The landmarks and new features after B2 (`docs/terrain-design.md` §11–12), for the user's review. Positions are region metres (x east, −z north). The review page with pictures is built by a script and isn't committed; `tools/terrain_views.gd` takes the pictures.*
