# Outpost One · Chunk 2 Part B

Production assets for the pad inspection, beacon recovery, prepared landing site and Collapse pit lip.

| Package | GLBs |
| --- | --- |
| `Pad_Beacon/` | The Guarded beacon, prepared for the as-found, reseated and running states. |
| `Pad_Site/` | An amber corner marker, three cracked slab models and a separate crack-edge strip. |
| `Pit_Lip/` | Four loose rubble pieces with centred mass pivots, plus an undercut overhang. |

Each folder contains textured originals, JPG previews, packed Blender source, build scripts and a short hand-off guide. The GLBs use metres, +Y up and −Z forward. Terrain, game-side display content, collision bodies and interaction logic belong to the scene. The new beacon replaces the comms-mast stand-in for the inspection and recovery sequence. The stakes and beacon design studies are supplied in Part A.
